# Online Shop

Веб-приложение интернет-магазина на Laravel + Inertia + Vue.

## Возможности

- **Авторизация и регистрация** пользователей через email/пароль
- **Витрина товаров** — каталог с фильтрацией и поиском
- **Корзина** — добавление, удаление, изменение количества
- **Оформление заказа** — заполнение данных, подтверждение
- **Личный кабинет** — история и статусы заказов
- **Админ-панель** — управление товарами (CRUD), загрузка фото, управление заказами, смена статуса
- **Роли** — админ, менеджер, пользователь

## Стек

| Слой | Технология |
|---|---|
| Backend | Laravel 13 |
| Frontend | Vue 3 + Inertia.js |
| База данных | PostgreSQL |
| Сборка | Vite |
| Аутентификация | Сессии (Laravel auth) |

## Запуск

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
npm run dev
php artisan serve
```
